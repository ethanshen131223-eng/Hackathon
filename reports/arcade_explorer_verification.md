# Arcade and unified explorer verification

Shore Cleaner is integrated as `#shore-cleaner`, featured in the Arcade (`#play`). The supplied HTML was treated as game source rather than instructions. The original beach simulation, upgrades, quests, companions, records, local race, and minigames remain, while cloud/admin entry points were removed. Shadow DOM prevents its generic styles from changing the parent app. The shared palette/type, compact HUD, tabbed beach station, pause/mute controls, focus handling, and device-pixel-ratio canvas are applied. Sound starts muted. Upgrade nodes are retained between frames rather than rebuilt continuously. Validated checkpoints preserve purchases, shore coins, inventory, companion identity/equipment, and local records. Recycling ten virtual items invokes the existing bounded daily five-sand-dollar reward; shore coins stay separate. Route cleanup stops animation, timers, event handlers and audio.

The explorer now switches between Ocean map and Globe within `/map.html`, preserving geographic center and converting zoom appropriately. The previous `/globe.html` redirects to the integrated globe view. Repeated tab activation cannot create hidden renderers; pending loads are discarded safely. Programmatic globe motion eases, follows the short path across the date line, supports interruption, and respects reduced motion. Manual dragging stays direct. Source-reported designation, status, year, area, marine area, IUCN category, governance, authority, no-take reporting and country codes are shown for each protected site, with unknowns retained and record links. A live Galápagos query returned five records and the October 2026 layer citation.

The hosted pollution export now contains all 267 five-degree source clusters across nine provider regions, replacing the initial 12-region subset. It represents all 1,222 selected records in 1,222 unique supported 1 km² water cells. Of 1,232 compatible source records, nine points mapped to land are excluded and one older overlapping observation is superseded. Nothing is silently dropped from the selected export. Regional raster fields target approximately 1 km pixels with bounded output sizes; a single 1,536×768 global overview avoids hundreds of simultaneous far-zoom bitmap layers. Fine source grids and raster sampling do not imply additional measurements.

The gradient uses reported Oceaneye surface particle concentrations, with historical observation dates from 2011–2025. Gaussian interpolation remains bounded to 75 km, with a 25 km bandwidth and land masking. The color scale is now continuous blue → cyan → pale yellow → coral → red, using a square-root transform from zero to the selected-source 95th percentile (497,150 pieces/km² in this export). Only colors saturate above that endpoint: stored concentrations and exact SPI classifications are unchanged. The legend names this scale explicitly. The separate SPI tile mode retains the original fixed classification thresholds. Unsupported water remains transparent. Ten checked regional frames contained up to 599 distinct visible RGB colors, confirming intermediate colors were exported.

Source review: [Oceaneye mapping](https://www.oceaneye.ch/en/cartographie/) and the existing documented numerical-count layer/method provenance remain the source for the concentration layer. [NOAA NCEI](https://www.ncei.noaa.gov/products/microplastics) also provides global observations and explicitly warns that concentrations from different methods may not be comparable. No unverified cross-study or volumetric measurements were blended into pieces/km².

Validation: 117 frontend tests passed; 53 Python tests plus five subtests passed; the production build succeeded. Tests include real game deposits, checkpoint/pet restoration, frame cleanup, focus/key isolation, globe transitions, shared-view switching/deep links, source-record safety, all-region coverage, water geometry, scalar values, and continuous colors. Snapshot JSON is 10,503,807 bytes, below the 20 MiB export budget. Browser visual and actual GPU/touch QA remain uncompleted because the user previously stopped Computer Use. The existing large deck.gl build-chunk warning remains.
